# Inventory Invoices
This project has some endpoints (RestAPI) to create and edit invoices. <br/>
When this project is executed and started it looks to attach to a server discovery <br/>
to avoid using ports when being called from another microservice

## Execution
To execute this project, you might need to use jdk 24 and mvn 3.8.6 (I used those versions)
